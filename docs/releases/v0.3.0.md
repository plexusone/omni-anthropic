# Release Notes: v0.3.0

**Release Date:** 2026-07-05

## Highlights

- **Extended Thinking**: Native support for Anthropic extended thinking with `ThinkingConfig`
- **Cross-Provider Reasoning**: `ReasoningEffort` mapping to Anthropic thinking modes

## New Features

### Extended Thinking (ThinkingConfig)

Native support for Anthropic's extended thinking feature:

```go
import omnillm "github.com/plexusone/omnillm-core"

budget := int64(8192)
response, err := client.CreateChatCompletion(ctx, &omnillm.ChatCompletionRequest{
    Model: "claude-sonnet-4-6",
    Thinking: &omnillm.ThinkingConfig{
        Type:         omnillm.ThinkingTypeEnabled,
        BudgetTokens: &budget,
    },
    Messages: messages,
})
```

#### ThinkingType Values

| Value | Description |
|-------|-------------|
| `ThinkingTypeEnabled` | Enable thinking with explicit token budget |
| `ThinkingTypeDisabled` | Disable extended thinking |
| `ThinkingTypeAdaptive` | Let the model decide when thinking helps |

### Cross-Provider ReasoningEffort

Use the unified `ReasoningEffort` field for cross-provider compatibility:

```go
effort := omnillm.ReasoningEffortHigh
response, err := client.CreateChatCompletion(ctx, &omnillm.ChatCompletionRequest{
    Model:           "claude-sonnet-4-6",
    ReasoningEffort: &effort,
    Messages:        messages,
})
```

#### ReasoningEffort Mapping

| ReasoningEffort | Anthropic Behavior |
|-----------------|-------------------|
| `none` | Thinking disabled |
| `low` | Adaptive thinking |
| `medium` | Adaptive thinking |
| `high` | Thinking enabled (8192+ token budget) |

### Automatic Budget Calculation

When using `ReasoningEffortHigh`, the thinking budget is automatically calculated:
- Default: 8192 tokens
- If `MaxTokens` is set and 25% exceeds 8192, uses 25% of MaxTokens

This is a backwards-compatible release. The new `Thinking` and `ReasoningEffort` fields are optional and do not affect existing code.
