# Release Notes: v0.2.0

**Release Date:** 2026-04-25

## Highlights

- **Module Rename**: Renamed from `omnillm-anthropic` to `omni-anthropic`
- **Package Restructure**: Provider code moved to `omnillm/` subdirectory matching other provider modules

## Breaking Changes

### Module Path Change

The module path has changed:

```go
// Before (v0.1.x)
import _ "github.com/plexusone/omnillm-anthropic"

// After (v0.2.0+)
import _ "github.com/plexusone/omni-anthropic/omnillm"
```

### Package Structure

Provider code is now in the `omnillm/` subdirectory:

```
omni-anthropic/
└── omnillm/
    ├── adapter.go    # Provider implementation
    ├── config.go     # Configuration
    └── register.go   # Auto-registration
```

## Installation

```bash
go get github.com/plexusone/omni-anthropic@v0.2.0
```

## Usage

```go
import (
    omnillm "github.com/plexusone/omnillm-core"
    _ "github.com/plexusone/omni-anthropic/omnillm" // Auto-registers provider
)

client, _ := omnillm.NewClient(omnillm.ClientConfig{
    Provider: omnillm.ProviderNameAnthropic,
    APIKey:   os.Getenv("ANTHROPIC_API_KEY"),
})
```

## Dependencies

- `github.com/anthropics/anthropic-sdk-go` v1.38.0 (was v1.35.0)

## Upgrade Notes

Update your import paths from `omnillm-anthropic` to `omni-anthropic/omnillm`.
